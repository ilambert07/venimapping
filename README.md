# VeniMapping

VeniMapping is a ROS 2 project using the Allied Vision Vimba X camera SDK and ROS 2 camera driver.

## Development Setup

Development is performed inside a VS Code Dev Container. You do not need to install ROS 2 or the Vimba X SDK directly on your Mac.

To get started, follow the [macOS Development Setup Guide](docs/macos-quickstart.md).

## Requirements

- macOS
- Docker Desktop
- Visual Studio Code
- The Microsoft Dev Containers extension
- Access to the VeniMapping Git repository

## Development Checks

Once the development container is running, the setup guide explains how to:

- Verify the ROS 2 and camera-driver environment.
- Build the workspace.
- Configure VS Code IntelliSense.
- Run code-quality checks.
